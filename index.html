Privacy Policy — Audiobook Uploader

Effective date: 2026-11-17  ·  Contact: bou.kouha01@gmail.com  ·  Channel: kouha bou — https://www.youtube.com/@鲍叔呀

Audiobook Uploader is a private, owner-only script used to upload audiobook chapter videos to a single YouTube channel owned by the same person who operates the script. It is not a public application, has no other users, and is not offered to the public.

What data the script accesses

  • Only the operator's own YouTube channel and the videos the operator uploads to it, via the YouTube Data API v3 (videos.insert, thumbnails.set, playlistItems.insert, captions.insert).
  • It does not access, read, or store any other channel's data, any other user's data, comments, subscriptions, or watch history.

What data is collected

No personal data of any third party is collected, stored, or shared. The script processes only the operator's own audiobook content (audio rendered from an original AI-synthesized voice, cover images, and chapter text the operator owns the rights to) and the operator's own video metadata (titles, descriptions, playlists, subtitles).

How credentials are stored

The YouTube OAuth token is stored only on the operator's own local machine (yt_token.json). It is never uploaded, transmitted to any third party, or shared. No analytics, tracking, advertising, or third-party SDK is included in the script.

Data sharing

No data is sold, rented, or shared with any third party. The only external service the script communicates with is Google's YouTube Data API, solely to upload the operator's own videos to the operator's own channel, subject to Google's Privacy Policy and the YouTube API Services Terms of Service.

Data retention and deletion

The operator may revoke the script's access at any time from the Google Account permissions page. Deleting the local token file removes the stored credential immediately. Videos already uploaded to YouTube are managed through YouTube Studio.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
